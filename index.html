QianNiu Local Gmail Reader

A private, single-user Windows desktop utility that searches and reads existing QuillBot-related email through the Gmail API. It runs locally with Python; this website only provides application information.

The owner authorizes their own Google account using a Desktop OAuth client and a local loopback callback. The application requests only gmail.readonly. This is mailbox-wide read access; the utility limits its searches and processing to QuillBot-related messages. It cannot send, modify, or delete email.

Message bodies are parsed locally. OAuth tokens are protected with Windows DPAPI for the current Windows user. No Gmail data is sent to this website, GitHub Pages, or an AI service.

This personal tool is not offered for public sign-up. Support and privacy requests are handled through the support contact shown on its Google OAuth consent screen.
