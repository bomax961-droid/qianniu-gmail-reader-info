Privacy policy

This policy applies to QianNiu Local Gmail Reader, a personal Windows utility operated by its owner for their own mailbox.

Access and use

The utility uses Google's Gmail API with the https://www.googleapis.com/auth/gmail.readonly scope. Google grants read access at mailbox level, not per sender. The utility checks the authorized mailbox against its local configuration, then searches a small number of QuillBot-related messages and reads selected complete messages for local MIME and HTML parsing. It does not send, modify, or delete email.

Local storage and security

OAuth client configuration and the configured mailbox are stored in an access-restricted private directory on the owner's computer. Access and refresh tokens are encrypted using Windows DPAPI, tied to the current Windows user. Message bodies are processed in memory and are not intentionally retained by the reader. Diagnostic receipts contain status codes, counts, timestamps, and code version information; they exclude addresses, subjects, bodies, tokens, authorization codes, and message links.

Sharing and retention

The utility communicates with Google for authorization and Gmail API requests, using the computer's configured network connection or proxy. It does not sell Gmail data, share it with advertisers, transfer it to AI services, or use it for model training. Gmail data and credentials are not uploaded to this website or its GitHub hosting. The static website does not request access to Gmail; the hosting provider may process ordinary website access metadata under its own policy.

Saved authorization remains on the owner's computer until removed. The owner may revoke access from their Google Account's third-party connections at any time, and delete the local token and configuration. Revocation or refresh failure requires explicit reauthorization; background reads do not automatically open a browser.

Google API Services User Data Policy

QianNiu Local Gmail Reader's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact and changes

Only the owner uses this utility. For support or privacy questions, use the support contact displayed on its Google OAuth consent screen. This policy will be updated before any material change to how Google user data is accessed or used.
